## MCStudio 2.1.0（MC 工坊）

Minecraft Java **1.21.1** 的命令生成器 + 世界 / NBT 编辑器。这一版把重点放在
「第一次打开就能用明白」和「不会悄悄弄坏存档」上。

### 下载

| 文件 | 说明 |
|---|---|
| `MCStudio-2.1.0-win64.zip` | Windows 10/11 64 位**绿色版**：解压后双击 `MCStudio.exe` 即可，无需安装 Python |
| Source code (zip / tar.gz) | 源码发行版：`pip install -r requirements.txt` 后 `python main.py` |

> 首次启动会在 `%LOCALAPPDATA%\mcstudio\` 建立数据目录；如果你之前用过
> MCCmdGen，旧数据会自动复制过来（旧目录原样保留）。

### 界面重新设计

- **首页**：6 张任务卡（造物品 / 生成命令 / 编辑存档 / 编辑 NBT / 数据包 / 中文写命令）
  + 会随操作自动打勾的「3 步上手」清单 + 最近命令与最近存档。
  首屏不再是「一个世界都没打开」的空白编辑器。
- **四段式导航条**：品牌与首页 ｜ 模式切换（命令生成 / 双栏联动 / 世界编辑，带选中态）
  ｜ 查找命令与中文输入 ｜ 常用动作 + 「更多 ▾」（旧的工具条动作一个都没丢）。
- **命令面板 `Ctrl+K`**：一个输入框搜全部命令 / 页签 / 动作，中文关键字也行，
  ↑↓ 选择、Enter 执行。
- **底部上下文引导条**：步骤胶囊 + 一句话 + 此刻该点的按钮，随状态刷新
  （空输出 / 有命令 / 世界未打开 / 只读 / 有未应用修改 …）。
- **每个命令面板都有主行动条**：`重置为示例` `发送到输出区` **`复制命令`**，
  输出区主按钮 + 居中提示浮层（不再只闪 2 秒状态栏）。

### 世界编辑器更安全

- 「应用修改」现在**真的**会算差异、**真的**先备份（备份目录写进完成提示）；
- 新增 **「撤销并回滚磁盘」**：用这次写入前的备份把文件一起退回去（纯内存撤销只改内存，
  这一点现在也写清楚了）；
- 只读门禁重写：会写存档的入口才禁用，并给出「为什么灰」；
  创建快照 / 导出这类只读安全的操作保持可用；
- 未打开存档时用引导页盖住 15 个空表格；工具条加「全部页签 ▾」；
  双栏模式下也能在中间栏编辑存档；
- 大存档不卡界面：**区域批量替换**与**跨存档读取**在后台线程跑，带进度条与取消。

### 稳定性与数据安全修复

- **修复启动 / 反复打开「Execute 节点图」时的崩溃**（`Internal C++ object already deleted`）：
  该对话框同时设了 `WA_DeleteOnClose` 又调 `deleteLater()`，属于重复释放；
- 修复「失败的写盘事务把基准快照装进内存树」→ 之后差异恒为 0、**改动永远不落盘**；
- 修复空工作台点「发送到输出区」会**清空**用户输出区还提示成功；
- 修复数据包「删除函数」只删内存 → 磁盘 `.mcfunction` 残留、游戏照样加载；
- 「载入 / 导入」前确认，数据包页签加 `*` 脏标记；
- 破坏性确认框（清空历史 / 删除函数 / 删除预设 / 删除片段）默认按钮改为「否」；
- 区域批量运行期禁用按钮（旧版可重入 → 重复写同一批区块）；对话框在任务运行中关闭会先取消并收尾；
- 退出程序时先取消并等待后台的存档读取线程；
- 快捷键冲突清理：`Ctrl+Shift+S` 原被「收藏」和「NBT 另存为」抢 → 收藏改 `Ctrl+Shift+F`，
  快捷键帮助从 `F2`（表格就地编辑键）改为 `Shift+F1`；
- `mcgen.py world edit --apply` 统一走事务（备份 → 校验 → 原子写入 → 撤销点 → 刷新写盘基准）。

### 快捷键

`Ctrl+K` 命令面板 · `Ctrl+R` 重新生成 · `Ctrl+Shift+C` 复制输出 · `Ctrl+Shift+K` 打开存档 ·
`Ctrl+Shift+N` 打开 NBT · `Ctrl+Shift+H` 首页 · `F1` 上手向导 · `Shift+F1` 全部快捷键

### 验证

- `pytest -q` → **871 passed**（含 2054 subtests）
- `ruff check app tests mcgen.py tools` → 无告警
- `python tools/ui_smoke.py` → 44 条命令 / 9 个中心页签 / 15 个世界页签 / 所有对话框全点一遍，无异常

### 已知限制

- 目标版本是 Minecraft Java **1.21.1**，更高版本的命令与 NBT 结构未做适配；
- 区域文件写入、批量替换属实验功能：只支持等长替换，写入前会备份，建议先关游戏；
- 打包版未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

完整的三轮「问题 → 修法 → 验证」记录见 [docs/ui-redesign-2.1.md](docs/ui-redesign-2.1.md)。
