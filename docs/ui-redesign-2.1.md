# MCStudio 2.1 · GUI 重新设计与易用性改造报告

> 触发原因（用户原话）：**「太难用了，优化一下 gui，最好重新设计 gui，增强一下易用性，
> 交互引导太烂了，用户负体验严重」**。
>
> 这份文档记录：旧界面到底哪里难用（含逐条代码定位）、改了什么、怎么验证、
> 以及仍然没做的事。

---

## 1. 旧界面到底难用在哪

用离屏截图把旧版每个页面都抓了一遍（`build/shots-before/`），再逐条对照代码，
归纳出 **5 类**问题。下面是重新设计时真正落地修复的那部分。

### 1.1 首屏把人丢进空白编辑器（最致命）

旧版启动默认落在「编辑模式」，中间是**一个世界都没打开**的世界编辑器：

* 15 个页签全部可点，切过去全是空表格（`app/ui/world_panel.py:146`）；
* 唯一的提示是页面最底部一行淡灰色小字，且没有「打开存档」按钮；
* 真正的主力功能（命令生成）连入口都看不到。

新版：首屏是**首页**（任务卡片 + 3 步上手清单 + 最近命令 / 最近存档），
世界编辑器未打开存档时用整块引导页盖住空表格，并给两个按钮
（打开世界存档… / 看最近打开的世界）。

### 1.2 引导缺失：填完参数不知道下一步点哪里

* 面板里没有主行动按钮；唯一的「复制」在右侧输出区标题行，文案不含宾语；
* `Ctrl+R`（重新生成）只写在状态栏与快捷键里，用户不知道命令要先生成；
* 命令面板顶部明明显示 `/give diamond_sword`，输出区却是空的 ——
  因为面板构造时的示例命令不会同步过去，用户以为坏了。

新版：

* 底部常驻**上下文引导条**（`app/ui/shell/guidance.py`）：左侧是步骤胶囊
  （① 选命令 ② 填参数 ③ 复制到游戏），中间一句话说明当前状态，右侧是
  当前该点的按钮（主按钮高亮）。它会随状态变化：空输出 / 有输出 /
  世界未打开 / 世界只读 / 有未应用修改 / 停在占位页签……
* 每个命令面板底部加**主行动条**（`PanelActionBar`）：
  `清空参数` `发送到输出区` **`复制命令`**，并实时显示「当前命令 N 字符」；
* 输出区标题行改成两行，**「复制命令」是主按钮**（旧版挤成「制命」两个字）。

### 1.3 导航可发现性差

* 顶部工具条是一排 11 个纯文字按钮（「重新生成」「NBT → 输出」
  「目标选择器 → 输出」…），分不清主次，也看不出当前处在哪个工作区；
* 44 条命令只能靠左侧树翻，没有搜索框；
* 中间 7 个页签 + 编辑器 15 个页签横排，窄窗口必然溢出，
  右侧的「差异 / 跨存档 / 健康检查」被滚动箭头藏起来；
* **双栏模式点「世界编辑器」没有任何反应**（`_focus_world_editor`
  在 dual 下只 `setFocus()`，而中间栏此时显示的是命令页签）。

新版：

* 顶部导航条分四段：品牌 + 首页 ｜ 模式切换（命令生成 / 双栏联动 / 世界编辑，
  带选中态） ｜ 查找命令 / 中文输入 ｜ 常用动作 + **更多 ▾**（收纳旧的次要动作，
  一个都没丢）；
* **命令面板（Ctrl+K）**：一个输入框搜全部命令、页签、动作，支持中文关键字
  （「存档」「主题」「附魔」），↑↓ + Enter 直接执行；
* 命令树上方加筛选框（中文 / 英文 / 分类都能匹配）；
* 中间栏加「世界编辑器」页签，双栏模式下点它就能在中间栏编辑存档，
  切回别的页签自动回到命令面板；
* 编辑器工具条加「全部页签 ▾」下拉，15 个页签可跳可搜。

### 1.4 反馈不可见（状态栏 2 秒 = 没有反馈）

* 面板所有提示都走 `statusBar().showMessage(..., 1500~2500ms)`；
* 「全部 → 输出」只写文本、不切页签、不提示，用户不知道结果去哪了；
* 中文语义输入解析失败只弹一个气泡，`parseFailed` 信号全工程无人接收。

新版：

* 主窗口加**居中浮层 toast**（绿色，2.6 秒），复制 / 生成 / 打开存档 / 写入存档
  都有可见确认；
* 跨页签动作（批量生成 / 工作台 / 数据包 → 输出）会**标记输出页签未读**
  （「命令输出 ●」），状态栏也换成长文案；
* 命令搜索无匹配时给出可执行建议；中文输入失败给出句式提示。

### 1.5 安全绳是假的（世界编辑器）

这三条是审计里最严重的，属于「说了一套、做了一套」：

| 问题 | 旧行为 | 现在 |
|---|---|---|
| 「应用修改」不算差异 | `diff_against(self.capture(), …)` —— 拿当前状态跟自己对 diff，**永远「没有变化」** | `WorldSession.baseline`（写盘基准快照）+ `pending_diff()`，差异是真的 |
| 「应用修改」不建备份 | 直接 `world.save()`，绕过事务，与确认框里「会自动备份」矛盾 | 走 `session.transaction(snapshot=baseline).commit()`：备份 → 校验 → 原子写入 → 记撤销点 |
| 「撤销」后假装干净 | `save()` 清掉 dirty，撤销只换内存，界面显示「无未应用修改」 | `baseline_stale` 标记 + `unsaved_changes()`；`apply_changes` 会说明「内存与磁盘一致」并刷新基准 |
| 只读门禁方向反了 | 地图 / 区域 / 中文编辑这些**写**入口漏登记，点了才弹窗；「创建快照」这类**只读安全**操作却被禁用且不解释 | 重写 `_write_widgets()`（含各页签登记 `_extra_write_widgets`）；灰按钮 tooltip 说明「只读模式：先点『解锁编辑』」；快照 / 导出保持可用 |
| 写入结果看不见 | `_run_bridge` 把差异写进「差异」页签却不切过去，还丢掉了备份路径 | 写入后自动切到「差异」页签，状态栏显示 `TransactionResult.summary()` 与 `backups/<时间戳>/` |
| 区域写入默认坐标是错的 | 「写入区块…」对话框永远预填**区块索引表第 0 行**的坐标，选了 A 区块却填着 B | 预填当前选中行的坐标，没有选中才退回第一行 |

## 第三轮：卡顿与「假安全」的收尾（2.1.2）

第二轮报告里「仍然没做」的前两条这次做完了。

### 6.1 区域批量替换真的搬进了后台线程

* 新增 `_BatchWorker(QThread)`：dry-run 与写入都在后台跑，进度用信号回主线程；
* 对话框加了**进度条**与**取消**按钮，运行期 ①② 与取消按钮互斥（防重入，
  旧版执行到结束才禁用按钮，期间能再点一次 → 重复写同一批区块、重复备份）；
* 取消时区分两种语义并如实告知：dry-run 取消 = 什么都没写；
  写入取消 = **已写入的区块不会回滚**，请查 `backups/`。
* 跨存档页签的「读取来源存档」同样改成异步（复用 `WorldLoader`），
  带进度对话框与取消 —— 大存档不会再卡住界面。

### 6.2 「撤销」有了磁盘版

旧版 `undo()` 只回退内存：如果那一步已经写盘，磁盘上还是改过的内容，
用户很容易以为「撤销完了」。现在：

* `push_undo()` 会连**这次写入前的备份目录**一起记住；
* 世界编辑器新增「**撤销并回滚磁盘**」按钮（有可用备份时才亮）：
  内存回退 + 用备份把文件恢复 + 重新读盘 + 清空撤销栈，并告诉你恢复了几个文件；
* 纯内存的「撤销」文案也改成「如果这一步之前已经写盘，请点『撤销并回滚磁盘』」；
* 回滚备份（差异页签）后同样会清空撤销栈并说明原因（旧快照指向已被替换的节点，
  留着只会恢复一部分）。

### 6.3 只读门禁补齐 + CLI 统一走事务

* 画布「把选区写进区域区块…（实验）」补登记进门禁（这是审计里最后漏掉的一个写入口）；
* 世界设置类输入框（时间/天气/难度/出生点/边界/存档名 + 快速时间按钮）
  只读时整组禁用，并说明「只读模式：先点『解锁编辑』」；
* 没打开世界时「全部页签 ▾」与「导出当前表」置灰（跳过去只有引导页、导出只有空表）；
* 「重新载入」在有未写盘改动时会先确认；
* `mcgen.py world edit --apply` 改成走 `session.transaction(...).commit()`：
  备份 → 校验 → 原子写入 → 记撤销点 → 刷新写盘基准（旧实现绕过事务，
  没有撤销点、不写会话日志，同进程复用 session 时「有没有未写盘改动」会判错）；
  `world presets --apply` 也补上基准刷新与日志。

### 6.4 观感与窄窗

* `#8B949E / #6E7681 / #FF7B72` 这批硬编码颜色在 `main_window / panels /
  widgets / dialogs / bridge_drawer` 里全部换成主题语义色（浅色主题可读性）；
  `app/ui/**` 里现在只剩 `theme.py` 中的调色板定义。
* `/summon` 面板右侧「NBT 推荐」栏：窗口宽度 < 980px 自动收起，
  头部有开关；**用户手动点过之后就不再自动干预**（窄窗口原来会把坐标区挤成几十像素）。

### 6.5 验证

```bash

python -m ruff check app tests mcgen.py  # All checks passed
python mcgen.py world edit <存档> DayTime=13000 --apply   # 走事务，输出备份名
```

新增/更新的测试：`tests/test_usability_round2.py`（12 条，含线程与取消）、

### 6.6 还没做

## 第二轮全方位检查（2.1.1）

第一轮改完之后又跑了三路只读审计（新壳层 / 面板 / 世界-区域-数据包），
发现 **7 个「静默数据问题」** 和一批交互瑕疵，已全部修完。

### 5.1 数据安全（最严重的一批）

| 问题 | 后果 | 修法 |
|---|---|---|
| 失败的 `commit()` 把 `session.baseline` 的节点**直接装进活树**（`restore()` 不克隆） | 之后 `pending_diff()` 恒为 0，界面报「内存模型与磁盘一致」→ **用户改动永远不落盘** | `WorldSession.restore()` 改为克隆节点后再装；`apply_changes` 传 `dict(baseline)` 浅拷贝；新增回归测试断言「失败提交后仍能算出差异」 |
| `pending_diff()` 分不清「没有基准」与「没有差异」 | 无基准时会顺手 `set_baseline()`，把待写改动判成干净 | 返回 `None` 表示未知；`apply_changes` 提示「需要重新载入」而不是静默跳过 |
| `commit()` 里 `require_writable()` 在 try 之外 | 只读/结构异常直接抛进 Qt 槽：只打印 traceback，界面无任何提示 | 返回 `TransactionResult(ok=False, …)`，由调用方弹框 |
| 空工作台点「发送到输出区」emit 空串 | `_on_panel_activated("")` 把用户输出区**清空**，还提示「已发送」 | 面板空校验 + 主窗口空串兜底，都会给说明而不是清空 |
| 「清空历史 / 清空脚本 / 删除预设 / 删除片段 / 删除函数」的确认框默认按钮是 Yes | 回车即破坏性确认 | 全部显式 `defaultButton=No`，并说明「不可撤销」 |
| 数据包「删除函数」只删内存 | 磁盘 `.mcfunction` 残留，游戏照样加载 | 删除时同步删文件（含空目录清理），并在结果里说明 |
| 「载入目录 / 加载脚本」静默替换未保存内容 | 用户以为只是打开，实际丢改动 | 加确认；数据包页签标题加 `*` 脏标记（`dirtyChanged` → 主窗口改标题） |

### 5.2 卡顿与可重入

* 区域批量替换的 dry-run / 执行**运行期间立即禁用 ①② 按钮**（旧版执行到结束才禁用，
  期间能再点一次，会重复写同一批区块、重复备份），并加了带「取消」的进度提示；
  取消时明确告知「已写入的区块不会回滚，请查 backups/」。
* 数据包工程三栏不再写死 `setSizes([260, 620, 320])`，改成最小宽度 + 拉伸比例，
  中栏 420px 也不会被裁。

### 5.3 导航与状态一致性

* **双栏模式下中间栏空白**：点中间栏「世界编辑器」后再点导航条已选中的
  「双栏联动」，`center_stack` 会切回 `center_tabs` 而显示那个空占位页。
  现在由占位页签自己决定中间栏显示什么。
* **壳层导航不改工作区**：在「世界编辑」模式下按 Ctrl+K 选 `/give`
  （或点首页任务卡、打开 NBT），会出现「命令面板没有命令树/输出区」
  「NBT 加载了却看不见」。现在统一走 `_ensure_side_panes()`（editor → dual）。
* **引导条与面板状态自相矛盾**：引导条原来只看 `world.dirty`，
  面板按钮看 `session.unsaved_changes()`，撤销后一个说干净、一个亮着。
  现在都用 `unsaved_changes()`。
* **清空输出区后引导条不刷新**（早退分支漏了刷新）；**「最近使用」分组
  在筛选状态下会自己冒出来**；**编辑器独立成窗口后引导条/「世界编辑器」
  入口失效** —— 均已修。
* **快捷键冲突**：`Ctrl+Shift+S` 同时被「收藏」与「NBT 另存为」占用（后者胜出，
  收藏快捷键等于没有），`Ctrl+R` / `Ctrl+Shift+B` / `Ctrl+Shift+C` 在「更多 ▾」
  菜单里重复注册。收藏改为 `Ctrl+Shift+F`，菜单项不再注册快捷键，
  快捷键帮助从 F2 改为 `Shift+F1`（F2 是表格就地编辑键，窗口级 QAction 会吃掉它）。
  新增测试用 `findChildren(QAction)` 断言全窗口无重复快捷键。

### 5.4 性能与观感

* 引导条 `set_hint` / `set_steps` 幂等化：输出区**每敲一个字**都会刷新引导，
  旧实现每次都销毁重建一排按钮；现在状态没变就直接返回，且文案里不再带
  「N 字符」（字符数在输出区标题行已有）。
* 引导条旧按钮 `setParent(None)` 后再 `deleteLater()`，避免同帧里新旧按钮重叠。
* 引导条的动作按钮改为「拿不到回调就不显示」——旧实现会造一个点了没反应的按钮。
